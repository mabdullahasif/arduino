# Arduino Projects

A collection of Arduino sketches and projects.

## Projects

| Project | Description |
|---------|-------------|
| **Baremetal** | Bare-metal Arduino programming |
| **DHT** | DHT temperature & humidity sensor |
| **DHT-LCD** | DHT sensor with LCD display output |
| **HelloWorld** | Basic Hello World sketch |
| **Snake** | Snake game implementation |
| **i2c_scanner** | I2C device address scanner |
| **marque** | LED marquee display |

## Libraries

This repository includes the following libraries:

- **Adafruit Unified Sensor** – Sensor abstraction layer
- **Arduino LiquidCrystal I2C** – I2C LCD display driver
- **DHT Sensor Library** – DHT temperature/humidity sensor library
- **LedControl** – LED matrix & 7-segment display control

## Getting Started

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Clone this repository into your Arduino sketchbook folder.
3. Open any `.ino` file from the project folders.
4. Select your board and port, then upload.
